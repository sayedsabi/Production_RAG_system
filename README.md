
# Production RAG System

## Objective

Build a Retrieval-Augmented Generation (RAG) system that answers
questions over a technical document collection using relevant evidence.

## Planned capabilities

- Document ingestion and parsing
- Chunking and metadata management
- Embedding and retrieval
- Hybrid search and reranking
- Grounded answers with source citations
- Evaluation of retrieval and answer quality
- API, automated tests, and containerization

## Engineering principles

- Test components independently.
- Measure quality rather than relying on intuition.
- Investigate failure cases.
- Track experiments and architectural decisions.
